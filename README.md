# Nyota — Wedding Invitation Website Demo

Demo wedding-invitation website by Nyota Digital (Ravi Pratap Singh, Kanpur, India).

**Live demo:** https://nyota-demo.vercel.app

## What is in this repo

- `index.html` — the demo invitation page
- `vercel.json` — deployment config
- `deploy.py` — the deploy script used for the live demo
- `standard-pattern/` — the reusable invitation pattern, RSVP backend design and Google Apps Script for RSVP handling
